# Daftar migration (urutan wajib) dan isinya

Terapkan **berurutan**, satu berkas per eksekusi, **hanya** di proyek Supabase yang Anda setujui (mulai dari proyek UJI). Semua idempoten dan aditif; migration lama tidak pernah diubah (perbaikan = migration baru). Prosedur lengkap dan pemeriksaan sesudahnya: `docs/supabase-test-project-verification.md`.

1. `supabase/migrations/20261016000000_foundation.sql`
2. `supabase/migrations/20261016010000_phase1_onboarding_assets.sql`
3. `supabase/migrations/20261016020000_phase2_claim_profile_reserved.sql`
4. `supabase/migrations/20261016030000_phase3_editor.sql` — **baru di Phase 3**. Idempoten dan aditif (tidak menghapus data, tidak mengubah migration lama): constraint skema URL tautan, trigger batas 50 link + posisi otomatis + path gambar milik pemilik, fungsi `reorder_links(uuid[])` dan `change_username(text)`.
5. `supabase/migrations/20261016040000_phase4_publish.sql` — **baru di Phase 4**. Idempoten dan aditif (tanpa DROP data; tidak mengubah file migration lama). Isi: `publish_page_with_assets()` (publish atomik + verifikasi aset publik ada di Storage), `get_publish_state()`, `build_draft_payload()`, `get_public_page()` kini memuat `version`/`published_at`, `unpublish_page()` dikunci (kini mengembalikan boolean), dan **penutupan celah keamanan**: `publish_page()` tidak lagi dapat dipanggil client, kolom `*_published_path` tidak lagi dapat ditulis client.
6. `supabase/migrations/20261016050000_phase5_catalog.sql` — **baru di Phase 5**. Idempoten dan aditif (tidak menghapus data; tidak mengubah migration lama). Memperluas tabel `catalog_items`/`catalog_images` yang sudah ada (ringkasan, harga, label harga, sampul, thumbnail, metadata gambar); trigger batas 30 item/7 foto, posisi otomatis, path foto harus milik pemilik dan objeknya harus ada; sampul otomatis; RPC `reorder_catalog_items`, `reorder_catalog_images`, `set_catalog_cover`, `set_catalog_settings`; `build_catalog_payload()` (satu sumber bentuk katalog untuk draft dan snapshot); `build_draft_payload()`, `publish_page()` dan `publish_page_with_assets()` (tanda tangan sama) kini memuat katalog; constraint format CTA (`NOT VALID`: hanya menegakkan tulis baru); grant kolom (client tidak dapat menulis posisi, sampul, atau path publik). Satu-satunya perubahan bentuk constraint: unique `(item_id, position)` menjadi `DEFERRABLE` agar urutan foto dapat ditukar; data tidak disentuh. **Tidak ada bucket baru**: bucket `draft-assets` (privat) dan `public-assets` (publik) dari migration 2 sudah cukup.
7. `supabase/migrations/20261019000000_phase6_draft_save.sql` — **baru di Phase 6**. Idempoten dan aditif (tidak menghapus data; tidak mengubah migration lama). Menambah kolom revisi `pages.settings_rev` dan `profiles.profile_rev` (hanya dapat diubah lewat RPC) serta RPC `save_draft(...)`: simpan profil dan/atau tampilan secara atomik, dengan cek revisi (menolak simpan usang dengan galat `draft_conflict_*`) dan merge jsonb parsial yang tidak pernah menimpa `draft_config.catalog`. Tidak menyentuh `published_snapshots`. **Terapkan sebelum deploy kode Phase 6.**

8. `supabase/migrations/20261021000000_phase7_account_page_settings.sql` — **baru di Phase 7**. Idempoten dan aditif (tanpa DROP data; migration lama tidak diubah). Menambah tabel `username_released` (karantina 30 hari, RLS tanpa policy), kolom `pages.seo_rev`, RPC `save_seo` dan `update_profile_fields`; mengganti (CREATE OR REPLACE, tanda tangan sama) `change_username` (boleh saat terbit, menaikkan `profile_rev`), `get_public_page` (username snapshot ditimpa username profil saat ini), `get_publish_state` (username bukan "perubahan belum terbit"), `is_username_available` dan trigger `enforce_username_rules` (karantina). **Terapkan sebelum deploy kode Phase 7.**

9. `supabase/migrations/20261023000000_phase8_hardening.sql` — **baru di Phase 8**. Idempoten dan aditif (tanpa DROP data; migration lama tidak diubah). (a) `save_draft` mengunci `pages` lalu `profiles` (urutan sama dengan Terbitkan → tidak ada deadlock `40P01`); (b) mencabut `TRUNCATE/REFERENCES/TRIGGER` dari `anon`/`authenticated`; (c) mencabut `INSERT/DELETE` langsung pada `pages` dan `profiles` untuk client (dibuat oleh `claim_profile()`); (d) mencabut `is_username_available` dari `anon`. **Terapkan sebelum deploy kode Phase 8.**
